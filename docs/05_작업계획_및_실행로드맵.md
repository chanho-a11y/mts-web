## 1. 전체 범위 기능 인벤토리 (스펙 → 빌드 단위)

스펙(사용자 제공 랜딩페이지 구조)을 빌드 모듈로 분해. 각 모듈은 03 기술사양서의 데이터 모델·API에 매핑.

### 1.1 공통/헤더/푸터
- 헤더: 소셜(@mtspacecoffee/@normcorecoffee_official), **언어 토글(한/영, 접속국가 자동: KR→한국어, 그외→영어)**, 버거 메뉴, **상단 프로모션 배너**, 로그인/회원가입(우상단).
- 푸터: 회사명·대표·사업자번호·통신판매업신고·소재지·개인정보책임자·대표번호·이메일·환불정책·카피라이트·소셜.

### 1.2 회원/인증
- 회원가입: 이름·전화·이메일·주소(국가포함, **한국 주소검색 API=Daum 우편번호**)·사용언어·**보안질문 3종(답변 해시 저장)**·마케팅 동의. **자동 로그인(persistent session)**.
- 등급: 비회원 / 일반회원 / 기업회원(사업자등록증·승인) / 인플루언서(관리자 지정) / 관리자.
- 가입 시 일반/기업 선택. 인플루언서·등급 변경은 관리자만.

### 1.3 스토어프론트 (역할·브랜드별 뷰)
- **비회원**: 제한 카탈로그 + About + 커피정보 + 블로그 + 장바구니→팁→체크아웃 + Contact.
- **일반회원(normcore.com)**: MTSPACE 일반상품(블렌드·싱글오리진·머천·구독) + 놈코어(블렌드·리미티드) + 커피정보 + 블로그 + 회원정보 + 장바구니→팁→체크아웃.
- **기업회원(mtspace.coffee)**: 사업자전용 상품(블렌드·싱글오리진·머천) + 커피정보 + 블로그 + 회원정보(구매내역) + 장바구니→체크아웃(**팁 없음**) + Contact. **인플루언서 프로모션 미적용**.
- 카테고리: 카테고리 배너 + (썸네일+제품명+플레이버노트+가격) 카드.
- 커피정보: 농장정보·플레이버노트·추천레시피·**인포메이션 카드 다운로드**.

### 1.4 상품 상세 (신규 순서 — 03 §14 보강)
대표이미지+이름&플레이버 오버레이 → 한줄키워드 → 커피정보(원산지·품종·가공·플레이버·로스팅·중량) → 브랜드 로고 → 브랜드 철학 → 브랜드 소개 → 추천추출&레시피 → more information → 소셜. **제품 컬러(key_color)별 섹션 컬러·폰트 조정 가능**. AIEO/SEO 구조화.

### 1.5 장바구니/체크아웃/결제
- 장바구니 → (B2C/일반)**팁 선택** → 체크아웃. 기업은 팁 없음.
- 결제: 이니시스·카카오페이·페이팔(해외). 통화 KRW/외화. (03 §4)

### 1.6 관리자 (통합)
- **주문관리**: 목록(번호·날짜·이름·전화·이메일·주소·구분·금액)·상태(기본→확인→출고)·일괄 확인/출고(출고 시 고객 이메일).
- **제품관리**: 등록(=디자인 스튜디오 로직: 상세·카드뉴스·블로그 자동생성)·재고·상세페이지 양식.
- **고객관리**: 개인/기업 명단·구매내역·빈도분석·**기업 고객별 할인(제품별 금액/% 직접입력)**.
- **마케팅**: 프로모션(기간·대상·상품·금액·노출위치 체크박스)·**인플루언서 프로모션**(전용 랜딩·할인코드·파트너 로그인)·이메일(Gmail 연동·양식/서명 저장·분석)·매출분석·고객분석(등급별+인플루언서)·메타쇼핑 연결·**이메일 자동화**(신규제품 12h 후, 중단결제 5h 후, segment별).
- **콘텐츠관리**: 페이지별(헤더/바디/푸터 배경·내용)·폰트(Helvetica Neue, 자간 -2pt, 헤드라인 bold, 본문 light, 줄간격 160)·양식(상세·썸네일·블로그·인스타·카드뉴스)·블로그 라이터·카드뉴스·디자인자산(로고·파비콘)·지식베이스.
- **스토어 정보**: 연락처·이메일·관리자 추가·배송설정(국내 무게구간 + **해외 EMS 무게/부피 요금표**)·세금(국내 VAT 10%, 해외 0)·정책 6종.

### 1.7 콘텐츠 자동생성 (디자인 스튜디오/카드뉴스 엔진 — 03 §14·§14.7)
제품 등록 → 상세(네이티브)·라벨·카드뉴스·썸네일·블로그·인스타 자동 생성 → 검수 → 발행.

### 1.8 이미지 자산
- Archive.zip(617MB 원본, HEIC 포함) → **HEIC→WebP/AVIF 변환**, 페이지 슬롯 매핑, **CMS에서 교체 가능한 이미지 슬롯**(콘텐츠관리)로 관리.

## 2. 데이터 모델 증분 (03 §2 기준 신규/확장)

03 기술사양의 모델에 다음을 추가(상세 SQL은 스키마 마이그레이션 단계에서):
- `profiles.role` 확장: `guest|individual|business|influencer|admin`. `language`, `auto_login` 토큰.
- `security_questions`(profile_id, q1/a1_hash … q3/a3_hash) — **답변 해시 저장**.
- `business_accounts`(사업자등록증·승인) — 기존.
- `customer_discounts`(profile_id, product_id|category, type %/금액, value) — 기업 고객별 할인.
- `influencers`(profile_id, code, landing_slug), `promotions`(기간·대상·상품·금액·노출위치[]·type 일반/인플루언서).
- `shipping_zone`(국내/해외), `ems_rate`(country, weight_g, volume, price) — **EMS 요금표 시드**.
- `tip`(order_id, amount) 또는 order.tip_amount.
- `cms_block`(page, section header/body/footer, brand, background, content, font tokens), `design_asset`(logo/favicon), `kb_entry`(지식베이스), `email_template`(양식·서명), `email_automation`(segment, trigger, delay).
- 기존: product(+key_color·원두 프로파일), variant(SKU), variant_prices, customer_variant_prices, order/payment(provider·currency), faq, product_asset, content_draft, asset_template, generation_job.

## 4. 성능·SEO·AIEO 설계 (요구 반영)

- **렌더링**: 카탈로그·상세·블로그·FAQ는 SSG/ISR + on-demand revalidate. 개인화(장바구니·등급가)는 RSC+서버액션. 
- **데이터 로딩 최적화**: ① `resolve_price` 등 목록 가격은 SQL 뷰/lateral join으로 N+1 제거, ② 인덱스(slug·sku·category·storefront·status), ③ Supabase 커넥션 풀(pgbouncer)·엣지 캐시, ④ 이미지 `next/image`+WebP/AVIF+CDN, ⑤ 정적 자산 장기 캐시·코드 스플리팅, ⑥ 자주 안 바뀌는 데이터(카테고리·FAQ·KB)는 ISR 캐시, ⑦ 검색은 Postgres FTS 인덱스(한국어 우선).
- **SEO/AIEO**: SSR·메타·canonical·hreflang(한/영)·JSON-LD(Organization/Product/Offer/FAQPage/Article/Breadcrumb)·sitemap(도메인별)·robots·**llms.txt·agents.md(현 Shopify 수준 계승)**. 제품 사실은 텍스트(이미지 매몰 금지).
- 목표: Lighthouse/CWV(LCP<2.5s·CLS<0.1·INP<200ms), AI 검색 인용.
