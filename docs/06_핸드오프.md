## 4. 기술 스택·규칙 (요약)

- Next.js 14 App Router · TypeScript(strict) · Tailwind + shadcn/ui · Supabase(Postgres·Auth·Storage·RLS) · Vercel.
- 디자인 토큰: **Helvetica Neue · 자간 -2pt · 헤드라인 bold · 본문 light · 줄간격 160**. 브랜드 워드마크 불가침.

- 불변 규칙(02): 데이터 단일소스, SKU 필수, B2C/B2B·브랜드 격리(RLS), 가격 서버 단일결정(개별가→등급가→정가, +기업 고객별 할인), 제품=자산 단일소스, 텍스트 네이티브/이미지 래스터, 결제정보 비저장, 검수 게이트.
