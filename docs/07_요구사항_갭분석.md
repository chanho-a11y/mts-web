## 6. 가장 큰 미완성 (우선순위)

**A. 결제 실거래 (🔑 키)** — 이니시스/카카오/페이팔 키 + 콜백 승인 로직. 현재 주문은 생성되나 실제 결제 안 됨.
**B. 이메일 (🔑 Gmail)** — 출고 알림·이메일 발송·자동화(12h/5h). 구조만 있음.
**C. 디자인 스튜디오 풀 통합** — 라벨·인스타·5장 카드뉴스 엔진·블로그 자동발행·양식 편집기·지식베이스. 현재 텍스트 초안 + 단순 카드/썸네일만.
**D. 관리자 설정 UI** — 스토어정보·배송요금·세금·폰트·페이지 콘텐츠 편집, 디자인자산(로고/파비콘). DB엔 있으나 화면 없음.
**E. 기업 할인 방식** — %/금액 입력(스펙) vs 절대 단가(현재). 재구현 필요.
**F. 분석 심화** — 구매빈도·인플루언서·채널·등급별 분석.
**G. 콘텐츠/데이터** — 블로그 글 이전, 머천다이즈·리미티드 상품, 회원정보 편집 폼.
**H. 성능** — ISR/캐싱 도입(현재 force-dynamic), 부피기반 배송.
