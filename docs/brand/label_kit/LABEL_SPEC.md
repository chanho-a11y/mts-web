# MTSPACE COFFEE — Label Technical Specification (v1)

Importable label template for a label-production studio. Pairs with `MTSPACE-Label-Studio.html` (editor + label), `schema.json` (input model), `presets.json` (품목보고번호 data).

---

## 1. Physical format
- **Trim size:** 180 × 130 mm (18 × 13 cm), landscape.
- **Structure:** three equal boxes, each **60 mm** wide × 130 mm tall (1:1:1). Dividers: 0.3 mm hairline `#E3DAC8`.
- **Box padding:** left/right boxes **10.2 mm (top/bottom) × 8.8 mm (left/right)**; middle box **12.4 mm × 7.8 mm**.
- **Bleed/safety (for print):** add 3 mm bleed on export; keep text ≥ 5 mm from trim.
- CSS uses real `mm` units → 1:1 print. Screen preview scales the natural pixel size by `--scale` (transform), never the mm values.

## 2. Box contents
| Box | Contents | Background |
|---|---|---|
| **Left** | Brand foundation (wordmark + everyday excellence + color bar + 2 brand paragraphs); `IG: @…`; 품목제조보고 table; QR + 재활용(PET) cluster (below table, centered, equal height) | Oat `#F6F1E7` |
| **Middle** | Wordmark + everyday excellence; type label; **product name (largest, = table 제품명)**; English name (legal); flavour notes; volume | **Point color** block + hairline grid |
| **Right** | English name + color bar; coffee intro; `coffee Information` (specs table) + FLAVOUR; `recommended Recipe` (same row type) | Oat `#F6F1E7` |

## 3. Design tokens (CSS variables on `:root` / `.label`)
```
--oat #F6F1E7   --sand #ECE2D1   --ink #3C352C   --ink-soft #8A8173
--border #E3DAC8   --hair #EBE1CD   --paper #FFFFFF
--point / --point-text / --check   (per product, from point color)
--fs-brand 1.68mm  --fs-desc 1.72mm  --fs-info 1.64mm  --fs-recipe 1.6mm
--fs-name-mid 7.2mm(댐굳)/6.0mm(스팟라이트)/4.4mm(아리차)  --fs-en-mid 2.4mm(2.4/2.4/1.8 per preset)  --bar-w 40mm
```
> All token values mirror the finalized design 1:1 — it was authored at 5 px/mm (900×650 px = 180×130 mm), so every studio value = **DC px ÷ 5 mm**. Per-preset `nameSize`/`enSize` live in `presets.json`. `safetyFit()` only shrinks a value below its design default if the **user's own edits** would overflow the 130 mm trim.
Fonts: **Helvetica Neue / Pretendard** (info, wordmark, UI) · **Spectral / Noto Serif KR** (brand intro, notes — 명조) · **IBM Plex Mono (+Pretendard fallback for Korean)** (data, specs, recipe, table).

## 4. Point color — flavour × roast matrix
`point` = block background & accents; `point-text` = a deeper shade for text on oat (legibility); `check` = grid line over the block. Full table in `presets.json → pointColors`. Light roasts (citrus/peach) use white middle text on the lighter block.

## 5. Field → element binding
Authoritative map in `schema.json`. Key rules:
- **품목보고번호** is a pre-stored **dropdown** (`presets.json`). Selecting it fills tableName, name_en, type, notesEn, point, material, desc, infoLabel, flavor, specs[], recipe[].
- Middle **product name = table 제품명** (same string, enforced).
- English product name is **always present** under the Korean name (legal) and kept to **one line** (reduce `--fs-en-mid`).
- **Coffee info and recipe share one row type:** mono label (left) │ value (right). Recipe adds a faint condition sub-line.

## 6. QR
- Generated by **qrcodejs** into `#qr` from `qrUrl` (default `https://mtspace.coffee`), ECC level **M**, dark `#3C352C` on white, 11 × 11 mm.
- Replaceable: change `qrUrl`, or swap the `#qr` container content with an `<img>` for a custom code.

## 7. Direct editing
Every text node carries `data-field` + `data-editable contenteditable`. Editors can change **content, line breaks (Enter), and font size** (per-zone `--fs-*` controls). The studio mirrors edits back into the data model.

## 8. Export
- **Print/PDF:** `@page 180mm 130mm; margin 0`. Browser print → save as PDF (one label/page).
- **Data:** `데이터 내보내기` writes the current label's JSON (re-importable).
- For CMYK/press: export PDF, convert to CMYK in prepress; point colors are defined as RGB hex here — supply Pantone/CMYK equivalents at prepress if spot color is required.

## 9. Import into a label studio
1. Load `MTSPACE-Label-Studio.html` as the master template (self-contained; needs internet for fonts + qrcodejs, or bundle them).
2. Map your studio's data fields to the `data-field` attributes (see `schema.json`).
3. Use `presets.json` to seed the 품목보고번호 dropdown.
4. Each `data-field` node = one editable region; `--fs-*`, `--point*`, `--bar-w` = exposed parameters.
