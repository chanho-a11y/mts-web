# 카카오 소셜 로그인 — 셋업 가이드 (2026-07-23)

> 대상: mtspace-commerce (자사몰 new-website) · 개인(B2C) 회원 전용 카카오 간편 로그인/가입
> 코드는 반영 완료. 아래 설정을 마친 뒤 **환경변수 플래그를 켜면** 버튼이 노출된다.
> Supabase 프로젝트 ref: `apiskyivlvebpvvxfejq`

## 0. 개요 — 코드가 하는 일

- 로그인·회원가입 화면 상단에 "카카오로 시작하기" 버튼(개인 전용) 노출.
- 클릭 → 카카오 인증 → `/(auth)/callback` 에서 인가코드를 세션으로 교환 → `/account` 이동.
- 신규 카카오 사용자는 DB 트리거(`handle_new_user`)가 **자동으로 개인(individual) 프로필** 생성. 전화·주소는 비어 있고, 이후 체크아웃/마이페이지에서 채운다.
- 사업자(B2B)는 카카오 대상이 아니며, 기존 이메일 양식(사업자등록증 첨부·승인)을 그대로 사용.

## 1. 카카오 개발자 콘솔 (developers.kakao.com)

1. **애플리케이션 추가** → 앱 생성(앱 이름/회사명 입력).
2. **앱 키** 확인: `REST API 키`를 복사(= Supabase의 Client ID로 사용).
3. **카카오 로그인** 메뉴 → **활성화 ON**.
4. **Redirect URI** 등록(정확히 이 값):
   ```
   https://apiskyivlvebpvvxfejq.supabase.co/auth/v1/callback
   ```
5. **보안** → `Client Secret` **생성 + 활성화(사용함)** → 코드 복사(= Supabase의 Client Secret).
6. **동의 항목**:
   - `닉네임`(profile_nickname): 필수 동의 권장.
   - `카카오계정(이메일)`: 이메일을 받으려면 동의 항목 추가. 단, **이메일 필수 동의는 비즈니스 앱 전환·검수**가 필요할 수 있음. 이메일 미제공이어도 가입은 정상 동작(프로필 email이 비어 저장됨).
7. **플랫폼 → Web** 에 사이트 도메인 등록: `https://mtspace.coffee`, `https://normcorecoffee.com`.

## 2. Supabase 대시보드 (프로젝트 mtspace-commerce)

1. **Authentication → Sign In / Providers → Kakao** → Enable.
   - Client ID: 카카오 `REST API 키`
   - Client Secret: 1-5에서 만든 `Client Secret` 코드
2. **Authentication → URL Configuration**
   - **Site URL**: `https://mtspace.coffee`
   - **Redirect URLs**(Allow list)에 아래 모두 추가:
     ```
     https://mtspace.coffee/auth/callback
     https://normcorecoffee.com/auth/callback
     http://localhost:3000/auth/callback
     ```
   > 우리 앱 콜백 경로는 `/auth/callback` 이다(카카오에 넣는 supabase.co/auth/v1/callback 과 별개 — 둘 다 필요).

## 3. Vercel 환경변수

프로젝트 환경변수에 아래 1개 추가 후 재배포:

```
NEXT_PUBLIC_KAKAO_LOGIN_ENABLED=1
```

- 이 플래그가 `1`일 때만 카카오 버튼이 렌더된다(설정 전 오노출·오류 방지).
- 카카오/Supabase 설정을 마치기 전에는 플래그를 켜지 말 것.

## 5. 알아둘 점 (엣지 케이스)

- **같은 이메일 중복**: 기존에 이메일/비번으로 가입한 사람이 동일 이메일 카카오로 로그인하면, Supabase의 아이덴티티 연결 정책에 따라 별도 계정이 되거나 충돌할 수 있음. 필요 시 Supabase에서 "Link identities"(동일 이메일 자동 연결) 정책을 검토.
- **이메일 미제공**: 카카오가 이메일을 안 넘기면 `profiles.email`이 빈 값으로 저장(트리거 상 정상). 주문 확인 메일이 필요한 흐름에서는 체크아웃 이메일 입력으로 보완됨.
- **개인 전용**: 카카오 버튼은 항상 개인(individual) 계정을 만든다. 사업자 전환이 필요하면 이후 이메일 사업자 신청/관리자 전환으로 처리.
- **알림톡은 별개**: 카카오 "로그인"과 카카오 "알림톡(메시지)"은 다른 제품이다. 알림톡 도입은 별도 결정 항목(핸드오프 §9).
