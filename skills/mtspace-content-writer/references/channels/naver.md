# 네이버 블로그 (blog.naver.com/mtspace-coffee)

- 분량: 본문 1,500자 이상(공백 포함). 문체: 해요체, 캐주얼 정보형. 독자는 홈카페와 카페 사장님 격주(D-126).
- 원고 꼴: 원고.txt(제목, 대표 이미지, 본문, 태그, 발행 설정 섹션) + 이미지 4장(01 대표 1080 정사각, 02~04 1080x1350). 본문에 [이미지 2]~[이미지 4] 표시.
- HTML 금지. 표는 "항목: 값" 줄글, 목록은 줄바꿈, 인용은 ※.
- 태그 5개(제품 2~3 + 카테고리 2~3, 가공법 태그 금지). 링크 3개 이하, mtspace.coffee 검증 경로만.
- 자사몰 글과 25자 연속 일치 0, 구성도 다르게(전면 재작성).
- 네이버 한정 금지: N:W, split, QC 같은 B2B 약어.
- 말미 고정 블록: 원문, 제품, 납품 상담 링크. 로스팅 주기와 지역 문구는 넣지 않는다(8/25 패키지 기준은 D-138로 대체).
- 예약은 naver-blog-scheduler 스킬이 한다. 이 스킬은 원고까지.
